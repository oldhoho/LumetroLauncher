# LumetroLauncher

基于无障碍服务的 Android 桌面启动器，提供悬浮工作台、应用冻结、九键快速搜索等功能。

移植自 [queuejw/LumetroLauncher](https://github.com/queuejw/LumetroLauncher)，由 [oldhoho](https://github.com/oldhoho) 维护增强。

## ✨ 主要功能

### 🚀 工作台 (Workbench)
- 底部悬浮窗显示最近 7 个应用
- 1号槽位 → 最近任务键（Windows 风格图标）
- 2号槽位 → 当前前台应用（橙色高亮）
- 左右滑动查看更多应用
- 点击图标快速切换/启动应用
- 点击空白占位符 → 打开全部应用列表

### ❄️ 应用冻结
- 长按图标（1秒）+ 上滑 → 冻结/解冻应用
- 冻结应用自动从工作台列表隐藏
- 一键冻结列表中的应用（长按"❄️已冻结"）
- 查看已冻结 / 未冻结应用列表
- 冻结列表导出/导入

### 🔍 全部应用列表（九键面板）
- 拼音首字母分组（A-Z）
- T9 九键模糊搜索（如 9294 → 邮储银行）
- 字母索引跳转
- 点击应用启动 / 长按弹出菜单
- 固定到磁贴 / 隐藏应用 / 应用信息

### 🧩 磁贴面板
- 自定义布局，拖动排序
- 磁贴锁定（防止意外修改）
- 天气磁贴（支持切换城市）
- 自定义磁贴颜色、大小、圆角

### 👆 手势控制
- 主页上滑 → 打开全部应用列表
- 主页左滑 → 切换侧边栏
- 主页下滑 → 展开通知面板
- 三次连按音量键 → 打开侧边栏
- 左侧手势条 → 返回键

### 🎨 其他功能
- 使用系统壁纸作为桌面背景
- 图标包支持
- 面板背景自定义
- 应用列表搜索

## 📋 权限说明

| 权限 | 用途 | 是否必须 |
|------|------|----------|
| 无障碍服务 | 工作台、手势控制 | ✅ 核心依赖 |
| 悬浮窗 | 工作台显示 | ✅ 必须 |
| 使用情况访问 | 读取应用列表 | ✅ 必须 |
| Shizuku | 应用冻结 | ⚠️ 冻结功能需要 |
| 管理所有文件 | 壁纸、图标包 | ⚠️ Android 11+ 需要 |

## ⚠️ 注意事项

1. **首次启动**需要授予所有权限，否则部分功能不可用
2. **无障碍服务**是核心依赖，必须开启
3. **Shizuku** 需要单独安装，用于冻结功能
4. 部分功能需要 Android 8.0+

## 🔧 开发环境

- Android Studio / AndroidIDE
- Kotlin
- Gradle

## 📦 安装

1. 从 [Releases](https://github.com/oldhoho/LumetroLauncher/releases) 下载 APK
2. 安装后授予所有权限
3. 开启无障碍服务
4. 安装 Shizuku（如需冻结功能）
